ИНСТРУКЦИЯ ПО АУДИТУ И ВАЛИДАЦИИ ТРАНЗАКЦИЙ (API-ФОРМАТ)
================================================================================

ЗАДАЧА:
- Анализ транзакций (общее кол-во: 1864).
- Выявление логических, семантических и математических противоречий.
- Присвоение метрики доверия (trust_score: 1-10).
- Предложение нормализованных названий.

МАТЕМАТИЧЕСКИЙ АЛГОРИТМ РАСЧЕТА (acc.balance(i+1)):
1. Входящий баланс: prev_acc_tr_balance(i+1) или acc.balance(i).
2. Коэффициент (AccountEffect):
   - TPE-001 (Доход): 1
   - TPE-002 (Расход): -1
   - TPE-003 (Ревизия): 0
   - TPE-004 (Перенос): 1
   - TPE-005 (Корректировка): -1
3. Вычисление: delta = amount * AccountEffect(TypeID).
4. Итого: calculated_balance = acc.balance(i) + delta.
5. Контроль: статус "error" при разнице > 0.01 (точность до 2 знаков).

СЕМАНТИЧЕСКИЙ АНАЛИЗ:
- Проверка соответствия "entity_name" и "category_name" названию операции.
- Верификация контрагентов ("contragent_from_name", "contragent_to_name").
- Ссылка на транзакции строго по "code" (хронологический порядок).

КОНТРАКТ ОТВЕТА (JSON):
{
  "audit_results": [
    {
      "transaction_id": "string",
      "code": "integer",
      "trust_score": "integer",
      "status": "processed",
      "changes": {
        "suggested_correction": "string"
      },
      "reasoning": "string"
    }
  ],
  "ai_notes": "string"
}

ПРАВИЛА УПРАВЛЕНИЯ DYNAMIC MEMORY (ai_notes):
1. Кэширование: анализ блока 'AI-NOTES' для исключения дублирования выводов.
2. База знаний: накопление правил нормализации и типизация ошибок.
3. Ограничения: лимит 1500 токенов, структура с секциями [AI INTERNAL STATISTICS] и [EDGE CASES].
    Количество выявленных семантических ошибок: (пример 9.5)
    Количество примененных правил: (пример 10)
    Основные типы правил: (пример: "CNA-056, Баланс, отражает баланс системы", CNA-010, "Тройка", бутылированная питьевая вода, ENT-003, CAT-001 и т.д.)
Далее можете внедрять метрики на усмотрение в свободном формате.

4. Правила классифицируйте на свое усмотрение. Кешуруйте, чтобы не терять ценные данные на дальнейшей обработке.
