МЕТАДАННЫЕ РЕЕСТРА И ПРАВИЛА РАСЧЕТА
--------------------------------------------------------------------------------
- Общее количество записей: 1864
- Алгоритм: acc.balance(i+1) = acc.balance(i) + amount(i) * AccountEffect
- AccountEffect("type_id"):
  - TPE-001 (Доход): 1
  - TPE-002 (Расход): -1
  - TPE-003 (Ревизия): 0
  - TPE-004 (Перенос): 1
  - TPE-005 (Корректировка): -1

Изменение баланса счета транзакции в зависимости от типа и знака суммы транзакции:
Транзакция дохода может уменьшать баланс, если сумма операции отрицательная.
Транзакция расхода может увеличивать баланс, если сумма операции отрицательная.
Транзакция корректировки может увеличивать или уменьшать баланс в зависимости от знака суммы операции.

ТРАНЗАКЦИОННЫЕ ПОЛЯ
--------------------------------------------------------------------------------
- transaction_id: ID транзакции
- code: Порядковый номер
- transaction_name: Название
- type_id: ID типа (TPE-001...TPE-005)
- type_name: Название типа
- entity_id: ID сущности (ENT-XXX)
- entity_name: Название сущности
- account_id: ID счета
- account_name: Название счета
- amount: Сумма (может быть отрицательной)
- category_name: Название категории (CAT-XXX)
- acc_balance: Текущий баланс
- prev_acc_tr_balance: Предыдущий баланс
- prev_acc_tr_id: ID предыдущей операции по счету
- contragent_from_name: Контрагент-донор
- contragent_to_name: Контрагент-акцептор
- operation_date: Дата операции
