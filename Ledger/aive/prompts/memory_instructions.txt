================================================================================
ИНТЕГРАЦИЯ КОНТЕКСТА AI-NOTES (КЭШ БИЗНЕС-ЛОГИКИ)
================================================================================

ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ:
1. Поле {ai_notes} содержит накопленную базу знаний, типизированные ошибки 
   и правила нормализации, сформированные в ходе предыдущих итераций.
2. При анализе текущего батча данный блок используется как первичный 
   источник для семантической верификации и исключения повторных выводов.
3. Важно: Каждая итерация обязана обновлять {ai_notes} в соответствии с 
   результатами аудита, сохраняя структуру в рамках лимита 1500 токенов.
4. Статистика: общий учет, форма ведения открытая.

СТРУКТУРА ОБРАБОТКИ ПАМЯТИ:
--------------------------------------------------------------------------------
- КЭШ ЛОГИКИ: Применение исторических выводов к текущим данным транзакций.
- АКТУАЛИЗАЦИЯ: Дополнение базы знаний новыми наблюдениями и правилами 
  нормализации для будущих транзакций (1864 всего).
- КОМПРЕССИЯ: При приближении к лимиту токенов (1300+) приоритет отдается 
  сутевым правилам, удаляются дубликаты.
- ДИНАМИКА: Ведение накопительной статистики (общее кол-во, ошибки, 
  прогресс базы правил, сравнение темпов).

ПРИМЕНЕНИЕ:
Данный блок должен быть передан в систему обработки как часть входного 
контекста для обеспечения консистентности аудита транзакций. При 
формировании итогового JSON-ответа поле "ai_notes" обновляется актуальными 
данными сессии.
