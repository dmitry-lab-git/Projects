Произвести повторный анализ транзакций согласно прилагаемых данных и указать точные коррективы и краткое пояснение.

Расчет проверен. Данные на 1858 операциях подтверждены и приведены в 100% соответствии с текущим актуальным сальдо счетов.
Следующие поля выверены и точны (не проверяйте эти поля без надобности):
- transaction_id: ID транзакции
- code: Порядковый номер
- type_id: ID типа (TPE-001...TPE-005)
- type_name: Название типа
- account_id: ID счета
- account_name: Название счета
- amount: Сумма (может быть отрицательной)
- acc_balance: Текущий баланс
- prev_acc_tr_balance: Предыдущий баланс
- prev_acc_tr_id: ID предыдущей операции по счету
Внимание. Важно. Расчет проверен. Не тратьте ресурс на пересчет.
Уделите внимание следующим полям:
- type_name: Название типа
- entity_name: Название сущности
- category_name: Название категории (CAT-XXX)
- contragent_from_name: Контрагент-донор
- contragent_to_name: Контрагент-акцептор
Сфокусируйте внимание строго на семантическое соответствие полей транзакции.
