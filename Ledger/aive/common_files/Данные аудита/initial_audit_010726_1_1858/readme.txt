aive/
├── main.py                  # Точка входа, оркестрация пайплайна
├── api_utils.py             # Модуль 1: secure_api_call (защищенные вызовы)
├── prompt_utils.py          # Модуль 2: prompt_prepair_code (сборка промптов)
├── keywords.extraction.py   # Модуль 3: extract_keywords (логика извлечения)
└── config.py                # Настройки БД, клиента, логирования


api_utils.py - защищенное подключение через API.
Протокол взаимодействия: 
- выдерживают ритмичные паузы между успешными запросами.
- после 3 попыток подключения процесс останаваливается.
- на каждой попытке увеличивается время ожидания.
- проверяется вес промпта через и сравнивается с входным параметром ограничения.
