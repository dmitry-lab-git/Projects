II. ИНФОРМАЦИЯ ДЛЯ ПОВТОРНОГО ПРОХОДА
--------------------------------------------------------------------------------
Данный блок описывает методологию переработки проблемных 247 транзакций.

1. ЦЕЛЬ: Повторный анализ с передачей метаданных первичного аудита и
   дополнительных примечаний из aive_requests_log.
2. МЕТОДОЛОГИЯ:
   - Использование DISTINCT ON для исключения дубликатов первичных записей.
   - Обогащение контекстом: привязка ai_notes из логов через group_id.
   - Фиксация: создание новых записей в staging_audit_results с
     audit_type = 're_audit' и ссылкой parent_staging_id.
3. УПРАВЛЕНИЕ ПРОЦЕССОМ:
   - Статусная модель: Внедрение промежуточных статусов (pending_re_audit,
     processing_re_audit, manual_review) через dicts.dict_statuses.
   - Контроль: Перевод в статус 'manual_review' для ручной валидации
     оператором перед финальным применением (is_applied = false).
4. АРХИВАЦИЯ: Создание паспорта аудита 010726 для фиксации итерации
   переработки, версии промпта и статистического среза.

III. СВЯЗУЮЩИЕ ЗВЕНЬЯ
--------------------------------------------------------------------------------
- Связь осуществляется через transaction_id и parent_staging_id.
- Ручная проверка в DBeaver является обязательным этапом контроля
  качества между 're_audit' (автоматизированным) и 'processed'
  (финальным прикладным статусом).
================================================================================
Выборка для анализа:
SELECT DISTINCT ON (q.transaction_id)
    q.transaction_id,
    q.transaction_code,
    s.staging_id AS parent_staging_id, -- запоминаем, на основе какого аудита делаем повторный
    s.raw_response->>'trust_score' AS previous_score,
    s.reasoning AS previous_reasoning,
    s.diff_json AS previous_diff
FROM 
    audit.audit_process_queue q
JOIN 
    audit.staging_audit_results s ON q.transaction_id = s.transaction_id
WHERE 
    (s.raw_response->>'trust_score')::int < 8
ORDER BY 
    q.transaction_id, 
    s.created_at DESC; -- Сначала берем самые новые записи первичного аудита
