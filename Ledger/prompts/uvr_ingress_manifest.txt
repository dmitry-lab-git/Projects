DATA CONSTRAINTS & TABLE STRUCTURE:

TARGET TABLE: development.version_updates
   - code: int4 (Порядковый сквозной номер обновления, строго на 1 больше максимального текущего)
   - update_version_name: varchar(50) (Punchy, емкое инженерное название вехи на английском языке)
   - update_version_id: varchar(50) (Идентификатор обновления в формате UVR-XXX, например UVR-026)
   - version_id: varchar(50) (Идентификатор глобальной версии ядра, например VER-003 или VER-004)
   - registration_date: date (Дата регистрации/проведения изменений в формате YYYY-MM-DD. Обязательное поле, совпадает с датой обновления)
   - description: text (Подробное описание сути изменений на русском языке: архитектурные решения, обоснования, логика процессов)
   - affected_objects: text (Перечень затронутых объектов через запятую: скрипты, таблицы, схемы, пути к папкам, crontab, функции)
   - created_at: timestamptz (Метка времени создания записи в БД, заполняется автоматически или текущим моментом)

RULES FOR DATA PARSING:
1. Автоматический расчет Code: Если в контексте указано, что последняя запись была №38, новая запись ОБЯЗАНА получить код 39, а идентификатор — UVR-039.
2. Логика Имен: Поле `update_version_name` должно звучать профессионально на английском.
3. Полнота объектов: Все упомянутые таблицы, скрипты или файлы должны быть извлечены из текста и аккуратно перечислены в `affected_objects`.
4. Обязательность полей: При формировании INSERT-запроса всегда заполнять поле `registration_date` значением даты изменения (YYYY-MM-DD), чтобы исключить ошибку нарушения NOT NULL ограничения.

OUTPUT FORMAT:
Выдавать ТОЛЬКО чистый блок SQL-кода (INSERT). Никаких приветствий, комментариев markdown вне кода или пояснительного текста. 

Пример корректного INSERT:
INSERT INTO development.version_updates (code, update_version_name, update_version_id, version_id, registration_date, description, affected_objects, created_at) VALUES
(39, 'PWA Adaptation & Templates UUID Migration', 'UVR-039', 'VER-004', '2026-10-23', 'Описание изменений...', 'app: Reflex PWA, table: processing.transaction_templates', CURRENT_TIMESTAMP);
