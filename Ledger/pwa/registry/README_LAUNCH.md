# Локальное тестирование PWA на мобильном устройстве через WSL 2

## Архитектурная проблема
Сетевой интерфейс WSL 2 по умолчанию изолирован и принимает входящие соединения только на петлевом интерфейсе (`127.0.0.1`). Из-за этого мобильное устройство, находящееся в одной локальной сети (Wi-Fi) с хост-машиной, не может напрямую подключиться к портам разработки внутри подсистемы Linux.

## Логика работы скрипта автоматизации (`Start_PWA.bat`)
Для решения проблемы инициализируется командный файл Windows, который последовательно выполняет следующие задачи:
1. **Динамическое определение сетевого адреса:** Считывает текущий IPv4-адрес беспроводного адаптера ноутбука, выданный точкой доступа телефона (в подсети `192.168.43.0/24`).
2. **Маршрутизация трафика (`netsh interface portproxy`):** Создает правила проброса портов, перенаправляющие входящие TCP-запросы с внешнего IP-адреса хоста (порты `3000` и `8000`) на локальный адрес `127.0.0.1` внутри WSL.
3. **Конфигурация Брандмауэра Windows:** Добавляет разрешающие правила в Брандмауэр (Windows Defender Firewall) для беспрепятственного прохождения входящего трафика по целевым портам.
4. **Инициализация окружения и запуск приложения в WSL:**
   * Выполняет переход в рабочую директорию проекта: `~/Projects/Ledger/pwa`.
   * Активирует виртуальное окружение Python (`.venv`).
   * Динамически перезаписывает параметр `api_url` в конфигурационном файле `rxconfig.py`, подставляя актуальный IP-адрес хоста для корректного взаимодействия фронтенда с API.
   * Инкапсулирует процессы и запускает full-stack фреймворк `reflex`.

## Инструкция по запуску

### Шаг 1. Настройка сетевого окружения
1. Включите режим **Точки доступа (Wi-Fi модем)** на мобильном устройстве.
2. Подключите ноутбук к развернутой беспроводной сети.

### Шаг 2. Инициализация серверов разработки
1. На хост-машине (Windows) нажмите правой кнопкой мыши на файл `Start_PWA.bat`.
2. Выберите пункт **«Запуск от имени администратора»** *(необходимо для управления конфигурацией `netsh` и правилами брандмауэра)*.

### Шаг 3. Подключение с мобильного устройства
1. Откройте веб-браузер на телефоне.
2. Перейдите по адресу, сгенерированному скриптом в консоли:
   ```http
   http://<ДИНАМИЧЕСКИЙ_IP_АДРЕС>:3000
   ```

> **Примечание:** Сетевой адрес хоста является динамическим и может изменяться при каждом цикле перезапуска точки доступа. Скрипт автоматически актуализирует сетевые параметры и конфигурацию проекта при каждом запуске.
