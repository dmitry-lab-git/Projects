# Структура проекта Ledger PWA

## Журнал обновлений (09.10.2026)
- **Модуль «Кросс-базовый реестр и редактор проектов»**:
  - Реализован полнофункциональный модуль управления жизненным циклом проектов с In-Memory Join между БД `ledger` (`projects.registry`) и `household` (`projects.metadata`).
  - **Реестр проектов (`/projects`)**: страница чтения с поддержкой динамической фильтрации по доменам и статусам, группировки и модальным просмотром детальных параметров метаданных.
  - **Редактор проектов (`/projects/editor`)**: отдельная страница управления атрибутами проектов (`slug`, `title`, системный статус, JSONB-метаданные `meta`).
  - Интегрирован справочник статусов из `dicts.dict_statuses` с фильтрацией по `entity_type = 'PROJECT'`.
  - Реализован универсальный смарт-поиск с debounce (300 мс) по названию, UUID, slug и домену.
  - Настроены компоненты чтения (`pwa/ui/components/projects.py`), стейта (`pwa/state/projects.py`), страница реестра (`pwa/ui/pages/projects.py`) и страница редактора (`pwa/ui/pages/project_editor.py`).

## Корневые файлы и конфигурация
- `requirements.txt` — список зависимостей Python.

## Директория `pwa/`
Основной пакет приложения:

- `pwa/pwa.py` — главная точка входа приложения, инициализация страниц и роутинг Reflex.
- `pwa/db.py` — настройка подключения к базе данных и управление сессиями SQLAlchemy.
- `pwa/models.py` — общие определения и агрегация моделей.

### Модели (`pwa/models/`)
- `pwa/models/base.py` — базовый класс моделей SQLAlchemy (`Base`).
- `pwa/models/dicts.py` — справочники и классификаторы.
- `pwa/models/infrastructure.py` — модели инфраструктуры и связанных сущностей.
- `pwa/models/medicine.py` — модели медицинского домена (схема `medicine`).
- `pwa/models/transactions.py` — модели транзакций.
- `pwa/models/projects.py` — модели проектов и метаданных (`projects.registry`, `projects.metadata`).

### Состояние (`pwa/state/`)
- `pwa/state/main_state.py` — основное состояние приложения (MainState).
- `pwa/state/infrastructure.py` — состояние для работы с инфраструктурой.
- `pwa/state/medicine.py` — состояние для работы с медицинским модулем.
- `pwa/state/projects.py` — состояние кросс-базового реестра проектов и редактора (`ProjectsState`).

### Пользовательский интерфейс (`pwa/ui/`)
- `pwa/ui/__init__.py` — инициализация модуля UI.

#### Страницы (`pwa/ui/pages/`)
- `pwa/ui/pages/index.py` — главная страница приложения.
- `pwa/ui/pages/reports.py` — страница отчетов.
- `pwa/ui/pages/snapshots.py` — страница снимков данных (snapshots).
- `pwa/ui/pages/infrastructure.py` — страница управления инфраструктурой.
- `pwa/ui/pages/medicine.py` — страница управления медициной и здоровьем.
- `pwa/ui/pages/projects.py` — страница кросс-базового реестра проектов.
- `pwa/ui/pages/project_editor.py` — страница редактора проектов со смарт-поиском и модальными формами.

#### Компоненты (`pwa/ui/components/`)
- `pwa/ui/components/transaction_form.py` — компоненты формы транзакций.
- `pwa/ui/components/report_page.py` — компоненты отображения отчетов.
- `pwa/ui/components/infrastructure_form.py` — компоненты управления инфраструктурой.
- `pwa/ui/components/medicine_form.py` — компоненты управления медициной (справочники, приемы, дневник).
- `pwa/ui/components/snapshot_page.py` — компоненты для работы со снимками.
- `pwa/ui/components/projects.py` — компоненты таблицы проектов, фильтров и модальных окон деталей.
